# PocketDesk — start here

PocketDesk is a small Android-style home and a set of everyday tools.
It runs as an app on your phone. You can also choose it as your home screen.

**You do not need a computer or Git to install it.**

## 1. Install on your phone

1. Download **PocketDesk.apk**. APK means an Android install file.
2. If you downloaded **PocketDesk-Install.zip**, open it in Samsung **My Files** and tap **Extract** first.
3. Open **My Files → Downloads**.
4. Tap **PocketDesk.apk**.
5. Android may ask whether My Files can install this app. Allow it for this installation, then return to the install screen.
6. Tap **Install**, then **Open**.

If tapping the link does not download the file in ChatGPT, open this same conversation in your phone browser and try the download there. The ZIP gives you another download format.

This is a personal app built for you. It is not a Play Store app. If Android blocks the installation, read the message before changing anything. You can send the exact message back in this conversation.

PocketDesk needs **Android 8 or newer** and a working Android System WebView. It was built for Android 15 as its target version. It contains no native processor-specific code.

## 2. First steps

1. Open **PocketDesk**.
2. Tap **All apps** to see every tool.
3. Open **Settings**. Choose your theme, colour, background, and text size.
4. Open **Notes** and write a short note. It saves as you type.
5. Open **Files → Save backup** after you have added things you want to keep.

The home screen starts with the name **Chris**. You can change it in Settings.

## 3. Your main tools

| Tool | What you can do |
| --- | --- |
| Home | See the time, your next plan today, your tasks, and your favourite tools. |
| All apps | Open PocketDesk tools or your phone's installed apps. |
| Search | Find a tool, note, task, plan, or saved contact. |
| Notes | Write, search, pin, colour, export, delete, and restore notes. |
| Tasks | Add a task, choose a due date, and mark it done. |
| Calendar | Add local plans with a date, time, place, and notes. The week starts on Monday. |
| Clock | See 24-hour time for your phone, Vienna, Seoul, London, and New York. Use a stopwatch with laps or a small timer. |
| Calculator | Use numbers, brackets, decimals, and percentages. View calculation history. |
| Files | Choose a phone file, open recently chosen files, and save or restore a backup. |
| Photos | Choose photos and view smaller copies kept in PocketDesk. |
| Music | Choose an audio file, play or pause it, move through it, and change tracks. |
| Contacts | Keep a local list of names, numbers, email addresses, and notes. |
| Phone | Enter a number and open your normal phone dialer. |
| Messages | Write a message and open your normal message app to review and send it. |
| Internet | Search, open websites, and save bookmarks. Websites open in your phone browser. |
| Camera | Open your phone camera. Add the returned small photo copy when the camera provides one. |
| Settings | Change PocketDesk's look, text size, touch feedback, and favourite apps. Open real Android settings. |
| My phone | See your battery, model, Android version, network, and free storage. |
| Help | Read a simple guide inside the app. |

**Back** returns to the previous PocketDesk page. **Home** returns to the main screen. **Recent** shows PocketDesk tools you opened. Clearing Recent clears that list.

## 4. Use it as your home screen — optional

Try PocketDesk as a normal app first.

To use its home screen:

1. Open **PocketDesk → Settings**.
2. Tap **Use as your home app**.
3. Choose **PocketDesk** in Android's screen.

To go back to your Samsung home screen:

1. Open the normal **Android Settings**.
2. Search for **Default apps**.
3. Open **Home app**.
4. Choose your previous home app, usually **One UI Home** on a Samsung phone.

## 5. Good things to know

- Notes, tasks, calendar plans, contacts, bookmarks, and preferences are saved on this phone.
- Calendar plans are local to PocketDesk. They do not automatically sync or make reminder alerts.
- Use **Set a phone alarm** or **Open phone timer** for background alerts. Your phone's clock handles these.
- PocketDesk's own small timer alerts while PocketDesk is open. If you return after it has finished, it shows the finished message.
- The stopwatch saves its start time. Changing the phone's date or time can change its elapsed time.
- Music pauses when you leave PocketDesk. Audio support follows your phone's WebView; MP3 and M4A are useful formats to try.
- Imported photos are smaller copies, up to about 1600 pixels on the longest side. A camera return may be only a small preview.
- Imported audio is a full copy. Each audio file can be up to 100 MB. The media collection can hold 120 items.
- Removing a photo or audio copy from PocketDesk keeps the original phone file.
- The app holds up to 500 notes, 1000 tasks, 1000 calendar plans, 500 contacts, and 100 bookmarks, within its total saved-data size limit. It tells you if a change cannot be saved.
- A backup includes the lists and settings. Photos, audio, and access to recently chosen phone files are separate.
- Deleting the app removes its private saved data. Save a backup first if you want to keep it.

PocketDesk has **no account, adverts, tracking, or internet permission**. Opening a website uses your existing phone browser. You choose when to call or send a message in the phone's normal apps.

## 6. What was checked

The Android code compiled, and the APK signature was verified. Automated checks cover calculations, date handling, saved data, backups, screen actions, and calls from the interface to the Android helper.

The app has **not been tested on a physical Android phone**. A full browser rendering check could not run in the build environment, so the visual layout has not had a screenshot review. Phone-specific file pickers, camera apps, home selection, audio playback, and system screens still need a real-device check.

## 7. Project files

**PocketDesk-Project.zip** contains the complete Android project, a browser preview, build instructions, tests, and the app's personal signing key for future updates.

You do not need these files to install the app. Keep them if you want to ask Work or Codex to change PocketDesk later.

The browser preview is **PocketDesk-Preview.html** inside the ZIP. Open it in a browser to try the interface. Browser notes and settings save in that browser; preview photos and audio last for that page session. Phone actions work in the APK.
